## （1）制作アプリのタイトル
進化じゃんけん〜いま、じゃんけんが進化する〜

## （2）制作アプリの説明（40文字程度）
じゃんけんで勝つごとにじゃんけんの手が進化するゲーム。

## （3）工夫した点・こだわった点
じゃんけんで勝つと、じゃんけんの手が進化して攻撃力もアップする（負けた手はLv.1に戻る）。
じゃんけんの勝敗で決めるのではなく、攻撃力の数値を比較して勝敗を決めるようにしたこと。
攻撃力の算出のルールは主に２つ。
- （表示されている攻撃力）＋（ランダムで＋0~100）の数値を攻撃力として算出すること
- じゃんけんで勝った方の攻撃力はx2で算出。
（元ネタとしては昔遊んだデジモンのカードゲームをイメージして参考にしました）

## （4）難しかった点・次回トライしたいこと（または機能）
### ＜難しかった点＞
進化じゃんけんの仕様の整理の処理のフローを考えること。
データをどのように取得して入れ替えるかが難しかった。
（AIに仕様を投げたら一瞬で返ってきて、、、orz）
フロントエンドで調整するために、HTMLとJSの書き方を一度書き換えたこと。

### ＜トライしたいこと＞
本当はそれぞれの手を画像で表示したかったが時間がなくできなかったので追加したい。
あとは、リセットボタン、勝敗ログやLvアップ時に演出を出したい。
